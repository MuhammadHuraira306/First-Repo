Storage Estimator

This program converts storage from gigabytes (GB) to megabytes (MB).

The program asks the user to enter a storage value in GB and then converts it to MB using the conversion 1 GB = 1024 MB.

How to run:

1. Make sure Python is installed.
2. Open the terminal in the project folder.
3. Run the following command:

python storage_estimator.py

Example:

Input:
Enter storage in gigabytes (GB): 5

Output:
Storage in megabytes (MB): 5120.0
